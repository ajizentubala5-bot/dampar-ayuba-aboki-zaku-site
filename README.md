# Dampar Ayuba Aboki Zaku Official Profile

A simple, responsive profile website for Hon. Dampar Ayuba Aboki Zaku, built as a static GitHub Pages project.

## Files
- index.html
- styles.css
- script.js

## Local preview
Open the project folder in a browser, or run:

python -m http.server 8000

Then visit:

http://localhost:8000/

## GitHub Pages deployment
1. Create a new GitHub repository.
2. Push this folder to the repository.
3. In GitHub, open the repository > Settings > Pages.
4. Select the main branch and root folder.
5. Save.

Your website will be published at:
https://<your-github-username>.github.io/<repository-name>/
